Steg 4 — Manuell stegning med knappar

Mål

Lägg till två tryckknappar för manuell stegning. Knapp 1 matar en klockcykel per tryck. Knapp 2 kör fram till nästa instruktion (SYNC).

Nya komponenter

AntalKomponent
2Tryckknappar
1Kopplingstråd (SYNC → D7)

Kopplingsschema

Arduino-kod

Två tryckknappar ger oss full kontroll över exekveringen. Eftersom W65C02S är helt statisk kan klockan stoppas hur länge som helst — vi kan stega igenom programmet i vår egen takt. Knapp 1 ger en enskild klockpuls, knapp 2 kör tills CPU:n signalerar en ny instruktion via SYNC-pinnen. Detta är ovärderligt för att verifiera att varje instruktion i testprogrammet exekveras korrekt.

// -----------------------------------------------------------
// Steg 4 — Manuell stegning med tryckknappar (lägg till i befintlig kod)
// -----------------------------------------------------------

// Nya pinnar för knappar och SYNC-signal
#define SYNC 7       // CPU pin 7 → Arduino D7 (opcode fetch-indikator)
#define BTN_CLK   5  // Knapp 1: en klockcykel per tryck
#define BTN_INSTR 6  // Knapp 2: kör till nästa instruktion

// --- Följande läggs till i setup() ---

void setup() {
  // ... befintlig kod från steg 1–3 ...

  // SYNC är en utgång från CPU:n:
  //   HÖG = CPU:n hämtar första byten av en ny instruktion (opcode fetch)
  //   LÅG = CPU:n är mitt i en flercyklig instruktion
  pinMode(SYNC, INPUT);

  // INPUT_PULLUP aktiverar Arduinons inbyggda pull-up-motstånd (~20 kΩ).
  // Knappen kopplas mellan pinnen och GND:
  //   Otryckt = pull-up drar pinnen HÖG → digitalRead ger HIGH
  //   Tryckt  = knappen kortsluter till GND → digitalRead ger LOW
  pinMode(BTN_CLK,   INPUT_PULLUP);
  pinMode(BTN_INSTR, INPUT_PULLUP);
}

// --- Ersätt loop() med denna ---

void loop() {
  // --- Knapp 1: Enskild klockcykel ---
  // !digitalRead = aktiv låg (knappen drar till GND vid tryck).
  if (!digitalRead(BTN_CLK)) {
    delay(50);                    // Debounce: ignorera kontaktstudsar
    while (!digitalRead(BTN_CLK)); // Vänta tills knappen släpps
    delay(50);                    // Debounce på släpp
    pulse();                      // Kör en klockcykel
  }

  // --- Knapp 2: Kör fram till nästa instruktion ---
  if (!digitalRead(BTN_INSTR)) {
    delay(50);
    while (!digitalRead(BTN_INSTR)); // Vänta tills knappen släpps
    delay(50);

    // Pulsera klockan tills SYNC går HÖG, vilket betyder att
    // CPU:n precis har påbörjat en ny instruktion (opcode fetch).
    // Vi stannar då och kan inspektera adress och instruktion.
    do {
      pulse();
    } while (!digitalRead(SYNC));  // Loop så länge SYNC är LÅG
  }
}

Testning

  2. Knapp 2: Kör tills SYNC går hög (ny instruktion)
