Steg 8 — Assembler-bygge med ca65

Mål

Hittills har vi skrivit 6502-program som hårdkodade hex-bytes direkt i Arduinons setup(). Det fungerar — men det är inte hållbart i längden. Nu tar vi steget till riktig assembler med ca65, en professionell 6502-assembler från cc65-verktygslådan.

Ingen ny hårdvara. Samma kopplingar som steg 7. Allt nytt finns i byggkedjan.

Arbetsflödet blir:

  1. Skriv 6502-kod i src/program.asm — med labels, subrutiner och kommentarer
  2. PlatformIO kör ca65 + ld65 före C++-kompileringen
  3. Resultatet (program.bin) konverteras till en C-header (program.h)
  4. setup() läser PROGRAM[] och laddar in i minnesemulatorn

Du redigerar en läsbar assembler-fil — inte en lång rad write_mem()-anrop.

Nya verktyg

Ingen ny hårdvara — bara mjukvara. Dessa två program installerar du en gång, sedan bara rullar det på.

Byggkedjan

Så här går din assembler-kod från en textfil till körbar kod i processorn. Tre steg, helt automatiskt — PlatformIO sköter allt.

program.asm  ──ca65──▶  program.o  ──ld65──▶  program.bin  ──bin2h.py──▶  program.h
                                                          │
                                              (2048 bytes kod + 6 bytes vektorer)
                                                          │
                                              main.cpp ◀──┘  #include "program.h"

Minneskarta — hela adressrymden ($0000–$FFFF)

6502-processorn har 16 adresslinjer = 64 KB adressrymd. Blockens höjd är proportionell mot deras storlek (1 px per 128 bytes, minst 8 px).

$FFFF
vectors[6] — NMI, RESET, IRQ
6 B
$FFFA
oanvänt (returnerar $EA = NOP)
~30 KB
$8800
program[2048] — 6502-program
2 KB
$8000
oanvänt
~16 KB
$4010
W65C22 VIA (fysisk krets)
16 B
$4000
oanvänt
~15 KB
$0400
ram[1024] — ledigt RAM
512 B
$0200
Stack (JSR/RTS, PHA/PLA)
256 B
$0100
Zero page (snabbast)
256 B
$0000

0xEA = NOP — ofarlig fallback. CPU:n hoppar över oanvända adresser. Gul markering = Arduino rör inte dessa adresser, den fysiska VIA-kretsen svarar.

PlatformIO-byggskript

scripts/build_asm.py är en pre-build hook som PlatformIO kör före C++-kompileringen. Den anropar ca65, ld65 och bin2h.py i sekvens. Konfigureras i platformio.ini med extra_scripts = pre:scripts/build_asm.py.

# Byggscript för PlatformIO — anropas före C++-kompilering
# Kör ca65 + ld65 för att assemblera program.asm → program.h

Import("env")
import subprocess
import os

def build_asm(target, source, env):
    src_dir = os.path.join(env.subst("$PROJECT_DIR"), "src")
    asm_path = os.path.join(src_dir, "program.asm")
    obj_path = os.path.join(src_dir, "program.o")
    bin_path = os.path.join(src_dir, "program.bin")
    h_path   = os.path.join(src_dir, "program.h")
    cfg_path = os.path.join(src_dir, "program.cfg")

    print(f"[build_asm] Assemblerar {asm_path} …")

    # Steg 1: ca65 (assembler → objektfil)
    result = subprocess.run(
        ["ca65", "-o", obj_path, asm_path],
        capture_output=True, text=True
    )
    if result.returncode != 0:
        print("[build_asm] ca65 FAILED:")
        print(result.stderr)
        return result.returncode

    # Steg 2: ld65 (länka → binär)
    result = subprocess.run(
        ["ld65", "-C", cfg_path, "-o", bin_path, obj_path],
        capture_output=True, text=True
    )
    if result.returncode != 0:
        print("[build_asm] ld65 FAILED:")
        print(result.stderr)
        return result.returncode

    # Steg 3: bin → C-header
    script_dir = os.path.join(env.subst("$PROJECT_DIR"), "scripts")
    result = subprocess.run(
        ["python3", os.path.join(script_dir, "bin2h.py"), bin_path, h_path],
        capture_output=True, text=True
    )
    if result.returncode != 0:
        print("[build_asm] bin2h FAILED:")
        print(result.stderr)
        return result.returncode

    print(f"[build_asm] OK — {os.path.getsize(bin_path)} bytes → {h_path}")
    return 0

# Registrera som pre-build hook
env.AddPreAction("buildprog", build_asm)

bin2h.py — binär till C-header

Konverterar program.bin till PROGRAM[] (en PROGMEM-array) som main.cpp inkluderar.

#!/usr/bin/env python3
"""bin2h.py — konvertera program.bin till program.h (C-header med byte-array)."""

import sys

def bin2h(bin_path, h_path):
    with open(bin_path, 'rb') as f:
        data = f.read()

    lines = []
    lines.append('// Genererad från program.bin — redigera inte för hand')
    lines.append(f'// Storlek: {len(data)} bytes')
    lines.append('')
    lines.append('#include <avr/pgmspace.h>')
    lines.append('')
    lines.append(f'const unsigned char PROGRAM[] PROGMEM = {{')

    hex_bytes = []
    for i, b in enumerate(data):
        hex_bytes.append(f'0x{b:02X}')
        if (i + 1) % 16 == 0:
            lines.append('    ' + ', '.join(hex_bytes) + ',')
            hex_bytes = []
    if hex_bytes:
        lines.append('    ' + ', '.join(hex_bytes))

    lines.append('};')
    lines.append(f'const unsigned int PROGRAM_SIZE = {len(data)};')
    lines.append('')

    with open(h_path, 'w') as f:
        f.write('\n'.join(lines))

    print(f'bin2h: {bin_path} ({len(data)} bytes) → {h_path}')

if __name__ == '__main__':
    if len(sys.argv) != 3:
        print(f'Användning: {sys.argv[0]} program.bin program.h')
        sys.exit(1)
    bin2h(sys.argv[1], sys.argv[2])

6502-programmet i assembler

Samma 4-radersprogram som steg 7 — men nu som läsbar assembler med labels, subrutiner och nollterminerade strängar.

; 6502-program — VIA LCD
VIA_ORB  = $4000
VIA_ORA  = $4001
VIA_DDRB = $4002
VIA_DDRA = $4003

.segment "CODE"
.org $8000

reset:
    lda #$FF
    sta VIA_DDRB
    sta VIA_DDRA

    ; LCD-init (8-bitarsläge)
    lda #$30
    jsr lcd_command
    lda #$30
    jsr lcd_command
    lda #$30
    jsr lcd_command
    lda #$38          ; Function set: 8-bit, 2 rader
    jsr lcd_command
    lda #$0C          ; Display ON
    jsr lcd_command
    lda #$01          ; Clear display
    jsr lcd_command
    lda #$06          ; Entry mode
    jsr lcd_command

hello:
    ; Rad 1: cursor $00
    lda #$80
    jsr lcd_command
    lda #$01          ; RS=1
    sta VIA_ORA
    ldx #0
@l1:
    lda line1,x
    beq @l1_done
    jsr lcd_data
    inx
    jmp @l1
@l1_done:

    ; Rad 2–4: samma mönster med cursor $C0, $94, $D4
    ; ...

    lda #$01          ; Clear display
    jsr lcd_command
    jmp hello         ; Loopa

; Subrutiner
lcd_command:
    sta VIA_ORB
    lda #$04          ; RS=0, E=1
    sta VIA_ORA
    lda #$00          ; RS=0, E=0
    sta VIA_ORA
    rts

lcd_data:
    sta VIA_ORB
    lda #$05          ; RS=1, E=1
    sta VIA_ORA
    lda #$01          ; RS=1, E=0
    sta VIA_ORA
    rts

line1: .byte "=== 6502 VIA LCD ===", 0
line2: .byte "Hello from W65C02!", 0
line3: .byte "Arduino = RAM + CLK", 0
line4: .byte "smutje.se 2026", 0

.segment "VECTORS"
.org $FFFA
    .word $0000       ; NMI
    .word reset       ; RESET
    .word $0000       ; IRQ

Arduino-kod — setup()

Enda skillnaden från steg 7: programmet laddas från PROGRAM[] istället för hårdkodade write_mem().

// ==============================================================
// Steg 8 — Assembler-bygge med ca65
// ==============================================================
// 6502-programmet byggs från src/program.asm via ca65/ld65
// → program.h. PlatformIO kör assembler-stegen automatiskt.

#include 
#include "program.h"   // Genereras av byggskriptet (bin2h.py)

#define PHI2     2
#define RESB     4
#define RWB      3
#define SYNC     13
#define BTN_CLK  11
#define BTN_INSTR 12

uint8_t ram[1024];
uint8_t program_arr[2048];   // $8000–$87FF (6502-program)
uint8_t vectors[6];          // $FFFA–$FFFF

#define VIA_BASE 0x4000

// --- is_via() — är detta en VIA-adress? ---
// VIA sitter på $4000–$400F. Arduino ska INTE svara här —
// den fysiska W65C22-kretsen hanterar dessa adresser.
bool is_via(uint16_t addr) {
  return (addr >= VIA_BASE && addr < VIA_BASE + 16);
}

// --- read_mem() — slå upp ett minnesvärde ---
uint8_t read_mem(uint16_t addr) {
  if (is_via(addr)) return 0;           // VIA: blanda dig inte i
  if (addr >= 0xFFFA && addr <= 0xFFFF)
    return vectors[addr - 0xFFFA];      // Vektorer
  if (addr >= 0x8000 && addr < 0x8000 + sizeof(program_arr))
    return program_arr[addr - 0x8000];  // Program
  if (addr < sizeof(ram)) return ram[addr]; // RAM
  return 0xEA;                          // Fallback: NOP
}

// --- write_mem() — spara ett värde i minnet ---
void write_mem(uint16_t addr, uint8_t val) {
  if (is_via(addr)) return;             // VIA: rör inte
  if (addr >= 0xFFFA && addr <= 0xFFFF)
    { vectors[addr - 0xFFFA] = val; return; }
  if (addr >= 0x8000 && addr < 0x8000 + sizeof(program_arr))
    { program_arr[addr - 0x8000] = val; return; }
  if (addr < sizeof(ram)) ram[addr] = val;
}

// --- pulse() — en klockcykel med minnesemulering + VIA-pass-through ---
void pulse() {
  digitalWrite(PHI2, LOW);
  DDRA = 0x00;               // Släpp databussen direkt
  delay(10);

  uint8_t kl = PINF;         // CPU A0–A7
  uint8_t kh = PINK;         // CPU A8–A15
  uint16_t a = (kl << 0) | (kh << 8);
  bool rw = digitalRead(RWB);

  // Om CPU läser och adressen INTE är VIA — svara
  if (rw && !is_via(a)) {
    DDRA = 0xFF;
    PORTA = read_mem(a);
  }

  digitalWrite(PHI2, HIGH);
  delay(10);

  // Om CPU skrev och adressen INTE är VIA — spara
  if (!rw && !is_via(a)) write_mem(a, PINA);

  // Diagnostik
  Serial.print(rw ? "R" : "W");
  Serial.print(" $");
  Serial.print(a, HEX);
  if (a >= 0x4000 && !rw)      Serial.print("  <- VIA");
  else if (a >= 0x8000 && rw)  Serial.print("  <- OPCODE");
  else if (a == 0xFFFC)        Serial.print("  <- RESET-VEKTOR LAG");
  else if (a == 0xFFFD)        Serial.print("  <- RESET-VEKTOR HOG");
  Serial.println();
}

// --- setup() — ladda 6502-programmet från assembler-bygget ---
void setup() {
  pinMode(RESB, OUTPUT); digitalWrite(RESB, LOW);
  pinMode(PHI2, OUTPUT); digitalWrite(PHI2, LOW);
  pinMode(SYNC, INPUT);
  pinMode(BTN_CLK,   INPUT_PULLUP);
  pinMode(BTN_INSTR, INPUT_PULLUP);
  pinMode(RWB, INPUT);
  Serial.begin(115200);
  DDRK = 0x00; DDRF = 0x00; DDRA = 0x00;

  // --- Ladda programmet från PROGRAM[] (PROGMEM) ---
  // program.h innehåller en byte-array genererad från program.asm.
  // pgm_read_byte läser från PROGMEM (flashminne).
  Serial.println("Steg 8 — Assembler-bygge med ca65");
  Serial.print("Programstorlek: ");
  Serial.print(PROGRAM_SIZE);
  Serial.println(" bytes");

  for (unsigned int i = 0; i < PROGRAM_SIZE; i++) {
    write_mem(0x8000 + i, pgm_read_byte(&PROGRAM[i]));
  }

  Serial.println("Program laddat.");

  // Reset-sekvens
  for (int i = 0; i < 5; i++) pulse();
  digitalWrite(RESB, HIGH);

  // Kör ~2000 cykler för att hinna med hela programmet
  for (int i = 0; i < 2000; i++) pulse();
}

// --- loop() — fortsätt köra ---
void loop() {
  pulse();
}

Så här använder du det

1. Redigera assembler-koden:

nano src/program.asm

2. Bygg och ladda upp (Windows-maskinen):

pio run -t upload -t monitor

Viktigt: platformio.ini måste ha build_src_filter = +<*> -<program.asm> för att förhindra att AVR-assemblern försöker kompilera 6502-koden.

Vid varje bygge körs ca65 → ld65 → bin2h.py automatiskt. Ändrar du program.asm byggs allt om.

Testning och felsökning

  1. Öppna terminal och kör 
    pio run -e step8 -t upload -t monitor
  2. Du ska se "Programstorlek: 2054 bytes" i serieövervakaren
  3. LCD:n visar samma fyra rader som steg 7
✅ Förväntat: Samma resultat som steg 7, men programmet är nu byggt från en .asm-fil med ca65.

Om det inte fungerar

  • ca65: command not found? Installera cc65: 
    sudo apt install cc65
  • "No such file: program.h"? Första bygget måste generera den. Kör pio run -e step8 två gånger om det krävs.
  • CPU:n gör inget? Kontrollera att write_mem()-loopen faktiskt kopierar PROGRAM[] till program[]. Logga med Serial.print().
