Steg 7 — "Hello 6502!" via VIA och LCD

Mål

I steg 6 styrde Arduino LCD-displayen direkt. Nu tar vi nästa stora kliv: vi kopplar in en W65C22 VIA (Versatile Interface Adapter) — en I/O-krets som ger 6502-processorn 20 egna pinnar att styra. VIAn sitter på CPU:ns adress- och databuss, precis som ett RAM-minne, men istället för att lagra data styr den fysiska pinnar.

En 74HC00 (fyra NAND-grindar) avkodar adressbussen så att VIA:n hamnar på adress $C000–$C00F. VIAns port A (PA0–PA7) och port B (PB0–PB7) kopplas till en parallell LCD-display.

6502-programmet på $8000 gör följande:

  1. Sätter VIA:ns portar som utgångar
  2. Initierar LCD:n i 8-bitarsläge
  3. Skriver "Hello 6502!" — ett tecken i taget, genom att lägga ASCII-värdet på port B och pulsa enable-signalen på port A

När allt fungerar har vi en dator där CPU:n själv styr I/O via minnesmappade adresser. Arduino är nu bara minnesemulator och klocka — all logik för LCD:n körs på 6502.

Adressavkodning med 74HC00

74HC00:an har fyra NAND-grindar. Vi använder en av dem för att avkoda adresslinjerna:

  • Grind B (pins 4,5,6): A14 (pin 4) NAND A15 (pin 5) → /CS_VIA (pin 6)

Resultat: VIA:n aktiveras (CS1=HÖG, /CS2=LÅG) när både A14 och A15 är höga, dvs. vid adress $C000–$FFFF. Registerväljarna RS0–RS3 kopplas till A0–A3, vilket ger 16 register på $C000–$C00F.

VIAns port A används för LCD:ns kontrollsignaler (RS, R/W, E). Port B hanterar 8-bitars databussen. CPU:n sätter PA1=0 (write) vid alla LCD-accesser — R/W-linjen är alltså alltid låg i praktiken.

6502-program — "Hello 6502!"

Programmet ligger på $8000 och gör tre saker: (1) sätter VIA:ns portar som utgångar, (2) initierar LCD:n i 8-bitarsläge, (3) skriver "Hello 6502!" ett tecken i taget via VIA. För varje tecken: lägg data på PORTB, pulsa E (PA2) på PORTA.

VIAns register (adress $C000–$C003)

AdressRegisterFunktion
$C000ORB (PORTB)LCD data (DB0–DB7)
$C001ORA (PORTA)LCD kontroll (PA0=RS, PA2=E)
$C002DDRBData Direction B ($FF = alla utgångar)
$C003DDRAData Direction A

Att skriva ett tecken till LCD

  1. Sätt data: STA $C000 — skicka ASCII-tecknet till PORTB (LCD DB0–DB7)
  2. Sätt RS=1, E=1: LDA #$05; STA $C001 — PA0=RS=1 (data), PA2=E=1
  3. Sätt E=0: LDA #$01; STA $C001 — PA2=E=0 (fallande flank → LCD läser)

Testning

  1. Koppla in W65C22, 74HC00 och LCD enligt schemat
  2. Verifiera att VIA:n svarar på adress $C000–$C00F via serieövervakaren
  3. Skicka ett init-kommando till LCD:n via VIA — displayen ska visa svarta rutor på första raden (tecken på att den är i 8-bitarsläge)

Diagnostik med Arduino

När steg 7 inte fungerar — använd Arduinons serieövervakare och lediga pinnar för att hitta felet.

1. Verifiera att CPU:n startar

Serieövervakaren ska visa reset-sekvensen: R $FFFC, R $FFFD, R $8000… Om du ser W $0 eller W $1 har du samma grundproblem som tidigare — kontrollera BE (HÖG), PHI2 (pulser), RESB (HÖG efter reset).

2. Kontrollera om CPU:n når VIA-adresserna

Ser du R $C000, W $C002 etc? Då försöker CPU:n prata med VIAn. Om du inte ser några $Cxxx-adresser — dubbelkolla 74HC00-kopplingen och att VIA:ns bussanslutningar sitter rätt.

3. Mät med multimeter/scope

  • PHI2 (CPU pin 37): Ska pulsera ~20 Hz (går att se med LED)
  • BE (CPU pin 36): Måste vara HÖG (~5V). LÅG = bussarna avstängda
  • RESB (CPU pin 40): HÖG efter reset (~5V)
  • VIA CS2B (pin 23): Ska gå LÅG när CPU adresserar $C000–$CFFF
  • VIA PHI2 (pin 25): Ska pulsera i takt med CPU-klockan

4. Anslut lediga Arduino-pinnar som logikanalysator

Koppla en sladd från en ledig Arduino-ingång (t.ex. D8) till en mätpunkt och läs av i pulse():

// I setup():
pinMode(8, INPUT);  // D8 → valfri mätpunkt

// I pulse(), efter adressläsning:
Serial.print(" D8="); Serial.print(digitalRead(8));

Användbara mätpunkter: VIA /CS2 (pin 23), 74HC00 pin 8 (utgång), LCD E (pin 6).

5. Vanliga fel

  • Glömt 5V till VIA: VIA pin 20 (VDD) måste ha +5V, pin 1 (VSS) måste ha GND
  • Glömt 5V till 74HC00: pin 14 → +5V, pin 7 → GND
  • CS1 (VIA pin 24) ej kopplad: Måste vara HÖG (+5V) — inte flytande
  • Databuss-kollision: Arduino driver PORTA samtidigt som VIA. Koden måste sätta DDRA = 0x00 vid VIA-adresser
  • För många komponenter på kopplingsdäcket: Ger spänningsfall. Mät VDD vid CPU, VIA och 74HC00 — alla ska vara >4.8V
