Steg 7 — "Hello 6502!" via VIA och LCD

Mål

I steg 6 styrde Arduino LCD-displayen direkt. Nu tar vi nästa stora kliv: vi kopplar in en W65C22 VIA (Versatile Interface Adapter) — en I/O-krets som ger 6502-processorn 20 egna pinnar att styra. VIAn sitter på CPU:ns adress- och databuss, precis som ett RAM-minne, men istället för att lagra data styr den fysiska pinnar.

En 74HC00 (fyra NAND-grindar) avkodar adressbussen så att VIA:n hamnar på adress $C000–$C00F. VIAns port A (PA0–PA7) och port B (PB0–PB7) kopplas till en parallell LCD-display.

6502-programmet på $8000 gör följande:

  1. Sätter VIA:ns portar som utgångar
  2. Initierar LCD:n i 8-bitarsläge
  3. Skriver "Hello 6502!" — ett tecken i taget, genom att lägga ASCII-värdet på port B och pulsa enable-signalen på port A

När allt fungerar har vi en dator där CPU:n själv styr I/O via minnesmappade adresser. Arduino är nu bara minnesemulator och klocka — all logik för LCD:n körs på 6502.

Logik: VIAn aktiveras när A14=1 OCH A15=1 (NAND ger LÅG ut → /CS2 LÅG → VIA på). Detta motsvarar adress $C000–$FFFF. CPU:ns A0–A3 går till VIAns RS0–RS3 vilket ger 16 register på $C000–$C00F. Arduino svarar på $8000–$BFFF, VIA:n tar $C000–$C00F — ingen överlappning.

6502-program — "Hello 6502!"

Programmet ligger på $8000 och gör tre saker: (1) sätter VIA:ns portar som utgångar, (2) initierar LCD:n i 8-bitarsläge, (3) skriver "Hello 6502!" ett tecken i taget via VIA. För varje tecken: lägg data på PORTB, pulsa E (PA2) på PORTA.

VIAns register (adress $C000–$C003)

AdressRegisterFunktion
$C000ORB (PORTB)LCD data (DB0–DB7)
$C001ORA (PORTA)LCD kontroll (PA0=RS, PA2=E)
$C002DDRBData Direction B ($FF = alla utgångar)
$C003DDRAData Direction A

Att skriva ett tecken till LCD

  1. Sätt data: STA $C000 — skicka ASCII-tecknet till PORTB (LCD DB0–DB7)
  2. Sätt RS=1, E=1: LDA #$05; STA $C001 — PA0=RS=1 (data), PA2=E=1
  3. Sätt E=0: LDA #$01; STA $C001 — PA2=E=0 (fallande flank → LCD läser)

Testning och felsökning

  1. Ladda upp koden och öppna serieövervakaren (115200 baud)
  2. Verifiera att CPU:n startar: du ska se R $FFFC, R $FFFD, R $8000…
  3. Leta efter VIA-adresser: W $C002, W $C003 betyder att CPU:n konfigurerar VIA:ns portar
  4. LCD:n ska visa "Hello 6502!" efter ~300 klockcykler (tar några sekunder vid 20 Hz)
✅ Förväntat: "Hello 6502!" på LCD:n — helt styrd av 6502 via VIA:n. Arduinon är nu bara minnesemulator och klocka.

Om det inte fungerar

1. CPU:n startar inte? Ser du W $0 eller W $1? Kontrollera BE (HÖG), PHI2 (pulser), RESB (HÖG efter reset).

2. Ser inga $Cxxx-adresser? Dubbelkolla 74HC00-kopplingen och att VIA:ns bussanslutningar sitter rätt.

3. Mät med multimeter:

  • PHI2 (CPU pin 37): ~2.5V medel (20 Hz fyrkant)
  • BE (CPU pin 36): >4.8V
  • VIA /CS2 (pin 23): ska gå LÅG vid $C000–$FFFF
  • VIA VDD (pin 20): >4.8V
  • 74HC00 VCC (pin 14): >4.8V

4. Arduino som logikanalysator: koppla D8 till en mätpunkt och lägg till i pulse():

Serial.print(" D8="); Serial.print(digitalRead(8));

5. Vanliga missar:

  • CS1 (VIA pin 24) flytande — måste ha +5V
  • 74HC00 VCC/GND glömt
  • Arduino driver databussen vid VIA-adresser — koden måste sätta DDRA=0x00
  • Spänningsfall — mät VDD vid CPU, VIA och 74HC00 (alla >4.8V)
