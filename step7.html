Steg 7 — I/O-expansion med W65C22 VIA och LCD

Mål

Koppla in en W65C22 VIA (Versatile Interface Adapter) som ger 20 I/O-linjer och styr en parallell LCD-display direkt från 6502:ans buss. En 74HC00 används för adressavkodning så att VIA:n och övriga enheter får rätt chip select-signaler. Nu är vi på väg mot en riktig dator — LCD:n styrs av CPU:n, inte av Arduino.

Kopplingsschema

Adressavkodning med 74HC00

74HC00:an har fyra NAND-grindar. Vi använder tre av dem för att avkoda adresslinjerna:

  • Grind 1 (pins 1,2,3): A14 NAND A14 = NOT A14 (båda ingångarna till A14)
  • Grind 2 (pins 4,5,6): A15 NAND A15 = NOT A15
  • Grind 3 (pins 9,10,8): NOT A14 NAND NOT A15 = A14 OR A15 → VIA /CS2

Resultat: VIA:n aktiveras (CS1=HÖG, /CS2=LÅG) när både A14 och A15 är höga, dvs. vid adress $C000–$FFFF. Registerväljarna RS0–RS3 kopplas till A0–A3, vilket ger 16 register på $C000–$C00F.

VIAns port A används för LCD:ns kontrollsignaler (RS, E). Port B hanterar 8-bitars databussen. LCD:ns R/W kopplas till GND eftersom vi bara skriver till displayen.

Arduino-kod — VIA-emulering

Arduinon måste emulera VIA:ns register på $C000–$C00F. När CPU:n läser/skriver till dessa adresser ska Arduinon svara med VIA-registervärden — inte vanligt RAM. VIAns port B (PB0–PB7) är ansluten till LCD:ns databuss, port A (PA0, PA2) till LCD:ns kontrollsignaler.

// VIA-emulering — lägg till i read_mem() och write_mem()

#define VIA_BASE 0xC000

uint8_t via_portb = 0x00;  // Output Register B (LCD data)
uint8_t via_porta = 0x00;  // Output Register A (LCD control: PA0=RS, PA2=E)
uint8_t via_ddrb  = 0xFF;  // Data Direction B (alla utgångar)
uint8_t via_ddra  = 0xFF;  // Data Direction A

uint8_t read_mem(uint16_t addr) {
  // VIA register ($C000–$C00F)
  if (addr >= VIA_BASE && addr < VIA_BASE + 16) {
    switch (addr & 0x000F) {
      case 0x0: return via_portb;  // ORB
      case 0x1: return via_porta;  // ORA
      case 0x2: return via_ddrb;   // DDRB
      case 0x3: return via_ddra;   // DDRA
      default:  return 0x00;
    }
  }
  // Vanligt RAM/ROM som tidigare...
  if (addr < 1024) return ram[addr];
  if (addr >= 0xFFFA) return vectors[addr - 0xFFFA];
  return 0xEA;
}

void write_mem(uint16_t addr, uint8_t val) {
  // VIA register
  if (addr >= VIA_BASE && addr < VIA_BASE + 16) {
    switch (addr & 0x000F) {
      case 0x0: via_portb = val; break;  // ORB → LCD data
      case 0x1: via_porta = val; break;  // ORA → LCD control
      case 0x2: via_ddrb  = val; break;
      case 0x3: via_ddra  = val; break;
    }
    return;
  }
  // Vanligt RAM
  if (addr < 1024) { ram[addr] = val; return; }
  if (addr >= 0xFFFA) { vectors[addr - 0xFFFA] = val; return; }
}

Testning

  1. Koppla in W65C22, 74HC00 och LCD enligt schemat
  2. Verifiera att VIA:n svarar på adress $C000–$C00F via serieövervakaren
  3. Skicka ett init-kommando till LCD:n via VIA — displayen ska visa svarta rutor på första raden (tecken på att den är i 8-bitarsläge)
  4. Skriv "Hello 6502!" till LCD:n via VIA:ns port B
✅ Förväntat: LCD:n initieras och visar text — helt styrd av 6502 via VIA:n. Arduinon är nu bara minnesemulator och klocka.

W65C22 VIA ─── PA0–PA2 ──→ LCD (RS, E)
            ─── PB0–PB7 ──→ LCD (DB0–DB7)
            ─── /CS2 ← 74HC00 (A14 OR A15)
            ─── CS1 ← +5V
            ─── RS0–RS3 ← A0–A3

VIAns register är minnesmappade på $C000–$C00F. CPU:n läser/skriver till VIA:n precis som till vanligt RAM — men istället för att lagra data styr den I/O-pinnar.
