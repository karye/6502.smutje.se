Steg 3 — Databuss och minne

Mål

Hittills har CPU:n kunnat tala om var den vill läsa (adressbussen). Nu kopplar vi in databussen — 8 ledningar som bär den faktiska informationen mellan CPU:n och minnet. Utan databuss kan CPU:n inte hämta instruktioner och är helt blind.

Vi kopplar också in R/W-signalen (pin 34). Den talar om ifall CPU:n vill läsa (HÖG) eller skriva (LÅG). Arduinon använder denna för att veta om den ska skicka data till CPU:n eller ta emot.

Arduinon blir nu en minnesemulator: en array ram[1024] lagrar data, och i varje klockcykel kollar Arduinon adressen och R/W — om CPU:n läser, lägger den ut rätt byte på databussen via PORTA. Om CPU:n skriver, läser Arduinon av vad som skrevs.

Vi laddar ett minimalt 6502-program på $8000: en enda NOP-instruktion ($EA) som gör ingenting och går vidare till nästa adress — vilket också är NOP. Resultat: CPU:n loopar för evigt, och vi kan följa varje steg i serieövervakaren.

Arduino-kod

Koden bygger vidare på steg 2. Den stora nyheten är pulse() som nu emulerar ett minne: läser adress + R/W, och antingen skickar data (DDRA=0xFF, PORTA=…) eller tar emot (DDRA=0x00).

// Steg 3 — Databuss och minnesemulering
#define PHI2 2
#define RESB 4
#define RWB  3

uint8_t ram[1024];
uint8_t vectors[6];

uint8_t read_mem(uint16_t addr) {
  if (addr >= 0xFFFA && addr <= 0xFFFF) return vectors[addr - 0xFFFA];
  if (addr < 1024) return ram[addr];
  return 0xEA;  // NOP — ofarlig fallback
}

void write_mem(uint16_t addr, uint8_t val) {
  if (addr >= 0xFFFA && addr <= 0xFFFF) { vectors[addr - 0xFFFA] = val; return; }
  if (addr < 1024) ram[addr] = val;
}

void setup() {
  Serial.begin(115200);
  pinMode(PHI2, OUTPUT); pinMode(RESB, OUTPUT); pinMode(RWB, INPUT);
  DDRK = 0x00; DDRF = 0x00; DDRA = 0x00;

  write_mem(0xFFFC, 0x00);  // Reset-vektor → $8000
  write_mem(0xFFFD, 0x80);
  write_mem(0x8000, 0xEA);  // NOP på $8000

  digitalWrite(RESB, LOW);
  for (int i = 0; i < 5; i++) pulse();
  digitalWrite(RESB, HIGH);
  for (int i = 0; i < 10; i++) pulse();
}

void pulse() {
  digitalWrite(PHI2, LOW); delay(10);
  uint16_t a = (PINF << 0) | (PINK << 8);
  bool rw = digitalRead(RWB);

  if (rw) { DDRA = 0xFF; PORTA = read_mem(a); }   // Läs: Arduino skickar data
  else    { DDRA = 0x00; }                          // Skriv: CPU:n driver bussen

  digitalWrite(PHI2, HIGH); delay(10);
  if (!rw) write_mem(a, PINA);                      // Spara det CPU:n skrev

  Serial.print(rw ? "R" : "W"); Serial.print(" $");
  Serial.println(a, HEX);
}

void loop() { pulse(); }

Testning och felsökning

  1. Öppna serieövervakaren (115200 baud)
  2. Du ska se: R $FFFC, R $FFFD, R $8000, R $8001…
  3. CPU:n loopar på NOP — perfekt för att verifiera att allt fungerar
✅ Förväntat: CPU:n läser reset-vektor, hoppar till $8000, exekverar NOP i loop.

Om det inte fungerar

  • Ser du W $0 eller W $1? CPU:n driver inte bussarna. Kontrollera BE (måste vara HÖG) och att PHI2 når CPU:n.
  • Ser du R $FFFC men inget mer? Databussen är felaktig. Kontrollera D22–D29 och att 100Ω-motstånden sitter på alla 8 ledningar.
  • CPU:n hoppar till konstig adress? Reset-vektorn är fel. Dubbelkolla write_mem(0xFFFC, 0x00) och write_mem(0xFFFD, 0x80).
  • Glöm inte 100Ω! Utan seriemotstånd kan en enda felaktig DDRA-inställning förstöra CPU:n eller Arduino.
