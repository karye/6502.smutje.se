Steg 3 — Databuss och minnesemulering

Mål

Koppla in databussen och RWB. Arduinon agerar minnesemulator — levererar instruktioner från en array. Vi laddar ett NOP-testprogram på $8000.

Nya komponenter

AntalKomponent
8100 Ω motstånd (databuss-skydd)

Kopplingsschema

⚠ Busskollision! När RWB = LÅG driver CPU:n bussen. Sätt PORTA till INPUT innan PHI2 går hög.

Arduino-kod

Här gör vi Arduinon till en fullständig minnesemulator. Eftersom Mega-brickans SRAM bara är 8 KB använder vi en mindre array (ram[512]) och hjälpfunktioner för att hantera adresser utanför detta område. Varje klockcykel läser Arduinon adressbussen, kontrollerar RWB-signalen och låtsas vara ett riktigt RAM/ROM-minne: vid läsning skickar den rätt byte ur arrayen till databussen, vid skrivning tar den emot och lagrar. Detta gör att vi kan köra godtycklig 6502-kod utan fysiskt minne — och verifiera att databussen, RWB och CPU:ns exekveringslogik fungerar.

// -----------------------------------------------------------
// Steg 3 — Databuss och fullständig minnesemulering
// -----------------------------------------------------------

#define PHI2  2   // Klockingång — Arduino D2 → CPU pin 37
#define RESB  4   // Reset (aktiv låg) — Arduino D4 → CPU pin 40
#define RWB   3   // Read/Write — Arduino D3 → CPU pin 34

// Mega har 8 KB SRAM — vi använder 512 bytes (gott för testprogram)
// och hjälpfunktioner för att hantera alla adresser korrekt
uint8_t ram[512];

uint8_t read_mem(uint16_t addr) {
  if (addr < 512) return ram[addr];
  return 0xEA;  // NOP — ofarlig fallback för oanvända adresser
}

void write_mem(uint16_t addr, uint8_t val) {
  if (addr < 512) ram[addr] = val;
}

void setup() {
  Serial.begin(115200);  // För utskrift av adress/instruktion

  pinMode(PHI2, OUTPUT);  // Arduino = klockmaster
  pinMode(RESB, OUTPUT);  // Arduino styr reset
  pinMode(RWB,  INPUT);   // CPU:n talar om ifall den läser eller skriver

  // Adressbuss: alltid ingångar — vi ska läsa CPU:ns adresser.
  DDRK = 0x00;  // PORTK = A8–A15
  DDRF = 0x00;  // PORTF = A0–A7

  // PORTA används för D0–D7 (databussen). I setup() sätter vi den
  // som ingång för säkerhets skull — riktningen ändras dynamiskt
  // i pulse() beroende på om CPU:n läser eller skriver.
  DDRA = 0x00;

  // --- Programmera reset-vektorn ---
  // När CPU:n kommer ur reset läser den $FFFC–$FFFD för att veta
  // var programmet börjar. Vi pekar om till $8000.
  write_mem(0xFFFC, 0x00);  // Låg byte av reset-vektor → $8000
  write_mem(0xFFFD, 0x80);  // Hög byte av reset-vektor → $8000

  // --- Ladda testprogram på $8000 ---
  // $EA = NOP (No Operation). CPU:n gör ingenting på 2 cykler,
  // ökar programräknaren och hämtar nästa instruktion — som också
  // är NOP. Resultat: en oändlig loop som är lätt att följa.
  // $EA = NOP läses automatiskt via read_mem() för adresser utanför ram[]
  // men vi laddar det explicit för tydlighet
  write_mem(0x8000, 0xEA);  // NOP

  // --- Kontrollerad reset-sekvens ---
  digitalWrite(RESB, LOW);   // Håll CPU i reset
  for (int i = 0; i < 5; i++) { pulse(); }  // 5 klockcykler under reset
  digitalWrite(RESB, HIGH);  // Släpp reset — nu börjar CPU:n köra!

  // Kör 10 cykler i setup() så att vi ser reset-vektorn i loggen
  // innan vi går in i loopen.
  for (int i = 0; i < 10; i++) { pulse(); }
}

// -----------------------------------------------------------
// pulse() — en komplett klockcykel med minnesemulering
// -----------------------------------------------------------
// Detta är datorns ”hjärtslag”. Under varje klockcykel måste
// Arduinon hinna läsa adress och RWB, leverera eller ta emot data,
// och hantera bussriktning — allt inom ~20 ms.
void pulse() {
  // -- Fas 1: PHI2 låg (förberedelsefas) --
  digitalWrite(PHI2, LOW);
  delay(10);  // Ge CPU:n tid att lägga ut adress och RWB

  // Läs 16-bitars adress från de två 8-bitarsportarna.
  uint16_t a = (PINK << 0) | (PINF << 8);

  // Läs RWB-signalen:
  //   HIGH = CPU:n vill LÄSA från minnet
  //   LOW  = CPU:n vill SKRIVA till minnet
  bool rw = digitalRead(RWB);

  if (rw) {
    // --- LÄSCYKEL: Arduinon levererar data till CPU:n ---
    // Sätt PORTA som UTGÅNG så vi kan driva databussen.
    // 100 Ω seriemotstånd skyddar mot busskollisioner.
    DDRA = 0xFF;           // PORTA utgång (8 bitar)
    PORTA = read_mem(a);   // Skicka ut minnesinnehållet
  } else {
    // --- SKRIVCYKEL: CPU:n driver databussen ---
    // Sätt PORTA som INGÅNG (hög impedans) så att vi inte
    // kortsluter CPU:ns utgångar. Utan detta kan kretsen skadas!
    DDRA = 0x00;           // PORTA ingång (högimpediv)
  }

  // -- Fas 2: PHI2 hög (arbetsfas) --
  digitalWrite(PHI2, HIGH);
  delay(10);  // CPU:n arbetar med data under hög klocka

  if (!rw) {
    // Efter stigande flank har CPU:n lagt ut giltig data.
    // Läs av PORTA och spara i vår minnesarray.
    write_mem(a, PINA);
  }

  // Logga varje minnesaccess för felsökning.
  // R = Read, W = Write, följt av adressen i hexadecimalt.
  Serial.print(rw ? "R" : "W");
  Serial.print(" $");
  Serial.println(a, HEX);
}

void loop() {
  pulse();  // Kontinuerlig körning — en klockcykel per varv
}

Testning

  1. Serieövervakaren visar $FFFC → $FFFD → $8000 (NOP-loop)
  2. LCD:n (om inkopplad) visar adress och instruktion i realtid
✅ Förväntat: CPU:n läser reset-vektor, hoppar till $8000, exekverar NOP i loop. Full minnesemulering!
