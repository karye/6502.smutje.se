Steg 5 — LCD-display

Mål

Koppla in en LCD1602 med I²C-backpack som visar aktuell adress och instruktion i realtid — direkt på kopplingsdäcket, utan datorskärm.

Arduino-kod

Med LCD-displayen blir bygget helt fristående — adress och data visas direkt på kopplingsdäcket utan serieövervakare. LCD1602 med I²C-backpack använder bara två signaltrådar (SDA + SCL) plus ström, vilket sparar pinnar. Displayen uppdateras efter varje klockcykel så att du i realtid kan följa CPU:ns arbete och verifiera att rätt instruktioner hämtas på rätt adresser.

// -----------------------------------------------------------
// Steg 5 — LCD1602 med I²C-backpack (lägg till i befintlig kod)
// -----------------------------------------------------------

// I²C-bibliotek: Wire är Arduinos inbyggda, LiquidCrystal_I2C
// installeras via bibliotekshanteraren (sök "LiquidCrystal I2C").
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Skapa LCD-objektet.
// Första argumentet är I²C-adressen — vanligast 0x27 eller 0x3F.
// Kör en I²C-skanner om du är osäker på vilken adress din display har.
// 16, 2 = 16 kolumner × 2 rader (standard för LCD1602).
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Globala variabler för aktuell adress och data — uppdateras i pulse().
uint16_t addr = 0;
uint8_t  data = 0;

void setup() {
  // ... befintlig kod från steg 1–4 ...

  // Initiera LCD:n — startar I²C-kommunikation och konfigurerar displayen.
  lcd.init();
  lcd.backlight();          // Tänd bakgrundsbelysningen

  // Visa ett startmeddelande på rad 0 (översta raden).
  lcd.setCursor(0, 0);      // Kolumn 0, rad 0
  lcd.print("W65C02S Ready");  // Bekräftar att displayen fungerar
}

// --- Uppdaterad pulse() med LCD-utskrift ---

void pulse() {
  // -- Fas 1: PHI2 låg — läs adress och RWB --
  digitalWrite(PHI2, LOW);
  delay(10);

  addr = (PINK << 0) | (PINF << 8);  // Spara adress globalt
  bool rw = digitalRead(RWB);

  if (rw) {
    DDRA = 0xFF;
    PORTA = mem[addr];
    data = mem[addr];               // Spara data globalt (för LCD)
  } else {
    DDRA = 0x00;
  }

  // -- Fas 2: PHI2 hög --
  digitalWrite(PHI2, HIGH);
  delay(10);

  if (!rw) {
    mem[addr] = PINA;
    data = PINA;                    // Spara skriven data (för LCD)
  }

  // --- Uppdatera LCD-displayen ---
  // Rad 0: visar aktuell adress i hex-format (t.ex. "A:8000")
  lcd.setCursor(0, 0);
  lcd.print("A:");
  lcd.print(addr, HEX);
  lcd.print("    ");  // Sudda ut rester från tidigare visning

  // Rad 1: visar data/instruktion i hex-format (t.ex. "D:EA")
  lcd.setCursor(0, 1);
  lcd.print("D:");
  lcd.print(data, HEX);
  lcd.print("    ");

  // Seriell utskrift behålls för felsökning.
  Serial.print(rw ? "R" : "W");
  Serial.print(" $");
  Serial.println(addr, HEX);
}

Testning

  1. LCD:n ska visa "W65C02S Ready" vid uppstart
  2. Vid varje knapptryck (steg 4) uppdateras displayen med aktuell adress och data
  3. Kör en I²C-skanner om displayen inte svarar — testa både 0x27 och 0x3F
✅ Förväntat: LCD:n visar adress och instruktion i realtid. Fullt fristående testbänk!
