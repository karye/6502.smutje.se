Steg 1 — Strömmatning och grundläggande klocka

Mål

Verifiera att W65C02S får spänning och att klockpulser genereras. Vi driver klockan från Arduino D2 med en lysdiod som visuell indikator.

Komponenter för detta steg

AntalKomponent
1W65C02S (DIP-40)
1Arduino Mega 2560
1Lysdiod (röd)
1220 Ω motstånd (klock-LED)
410 kΩ motstånd (pull-up: RDY, IRQB, NMIB, SOB)
1100 nF keramisk kondensator (avkoppling CPU)

Kopplingsschema

Arduino-kod

Koden genererar en fyrkantsvåg på pinne D2 som driver CPU:ns klockingång PHI2 (pin 37). W65C02S är en statisk CMOS-krets — till skillnad från äldre NMOS-6502 kan klockan vara hur långsam som helst, eller till och med stoppas helt, utan att processorn tappar sitt interna tillstånd. Syftet med detta första steg är att verifiera att CPU:n får spänning och att klockpulserna når fram — en grundläggande hårdvarukontroll innan vi kopplar in fler signaler.

// -----------------------------------------------------------
// Steg 1 — Generera klockpulser (PHI2) för W65C02S
// -----------------------------------------------------------

// PHI2 (Phase 2) är CPU:ns klockingång. Alla interna operationer
// synkroniseras mot denna signal. Vi driver den från Arduino D2.
#define PHI2 2

void setup() {
  // Sätt PHI2-pinnen som digital utgång.
  // CPU:n förväntar sig 0–5 V logiknivåer — Arduino Mega ger 5 V.
  pinMode(PHI2, OUTPUT);

  // Övriga kontrollpinnar (RDY, IRQB, NMIB, BE, SOB) dras höga
  // via externa pull-up-motstånd (3,3–10 kΩ) för att hålla CPU:n
  // i viloläge utan avbrott under detta grundtest.
}

void loop() {
  // --- Klockcykelns stigande flank ---
  // CPU:n utför interna operationer när PHI2 går från LÅG till HÖG.
  digitalWrite(PHI2, HIGH);
  delay(500);   // Håll hög i 500 ms → lysdioden lyser

  // --- Klockcykelns fallande flank ---
  // CPU:n förbereder nästa operation när PHI2 går från HÖG till LÅG.
  digitalWrite(PHI2, LOW);
  delay(500);   // Håll låg i 500 ms → lysdioden släckt

  // Resultat: en symmetrisk fyrkantsvåg på ~1 Hz.
  // Lysdioden blinkar i takt och bekräftar att klockan fungerar.
}

Testning

  1. Ladda upp koden
  2. Lysdioden ska blinka med 1 Hz (en gång per sekund)
  3. Mät 5 V mellan VDD (pin 8) och VSS (pin 21)
✅ Förväntat: Lysdiod blinkar stadigt. CPU:n är spänningssatt och klockad — redo för steg 2.
